# Lokal frontend recreation

This ZIP contains a frontend-only recreation inspired by the current public Lokal website, built as plain HTML/CSS/JavaScript.

## Run
Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Included
- Responsive Lokal homepage
- Brands page
- About page
- Careers page
- Contact form UI
- Product cards and product detail views
- Mobile responsive navigation/layout
- Scrollable sections
- External product links

## Important
This is a frontend recreation, not Lokal's original source code. No backend, CMS, authentication, database, or proprietary source code is included. Some brand/product links and the font are loaded from the public web.
